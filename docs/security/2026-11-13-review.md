## 新增功能带来的检查点

- **导入备份**：文件用 zod 校验。连接的地址和现有的不一致时，不保留已存的 Key，防止伪造的备份文件把 Key 引到别的服务器。
- **导出**：默认不含 API Key，需要手动打开。
- **确认卡片的键盘操作**：Esc 拒绝；回车允许一次，高风险步骤要 ⌘/Ctrl + 回车。正在输入文字、或焦点在按钮上时不响应。卡片出现后的 0.5 秒内仍然不接受允许。
- **右键菜单**：新增 `contextMenus` 权限（没有安装提示）。选中的文字和页面内容和从侧边栏附带时一样，按不可信数据处理。
- **更新检查**：只读取版本号和本项目的发布页地址，其他地址一律忽略。

## 剩余风险

- 安装时的权限提示仍然较重（`debugger`、`tabs`）。`debugger` 不能做成可选权限，是否提供不带它的商店版本尚未决定。
- 浮条的「继续」消息仍可能被攻破的渲染进程伪造，用来恢复被暂停的任务；它不能批准操作。
